TrackWise is a full-stack expense tracking application that helps users manage their daily expenses, visualize spending patterns, and get AI-powered insights from their transaction data.

**Live Demo:** https://trackwise-ai-expense-tracker-fullstack-2.onrender.com

---

## Features

* 🔐 User registration and login with JWT authentication
* 💰 Add and delete expense transactions
* 🗂️ Category-wise expense tracking
* 📊 Interactive spending visualization using Chart.js
* 🤖 AI-powered spending analysis using Google Gemini API
* 🗄️ Persistent data storage with MongoDB
* 🛡️ Protected backend routes using authentication middleware
* 📱 Responsive user interface

---
## Tech Stack

**Frontend:** HTML, CSS, JavaScript, Chart.js

**Backend:** Node.js, Express.js, REST APIs, JWT

**Database:** MongoDB, MongoDB Atlas

**AI:** Google Gemini API

**Deployment:** GitHub, Render
